# calculadora-custo-irrigacao
## Descrição do Problema
O projeto calcula o custo total de irrigação de uma horta com base na área, no tipo de solo e no custo por metro quadrado.
## Requisitos
- Receber a área da horta em m².
- Receber o tipo de solo (arenoso, argiloso, franco).
- Aplicar um fator de correção para o custo.
- Calcular e exibir o custo total.
## Exemplo de Uso
Entrada: área=50, solo='arenoso', custo_m2=2.5
Saída: Custo total: R$ 18.75
